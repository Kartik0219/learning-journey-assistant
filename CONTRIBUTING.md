# Contributing to Learning Journey Assistant

## Overview

Thank you for helping build the Learning Journey Assistant. This guide explains how the team works together on this repository, from setting up your environment to submitting changes for review.

## Getting Started

Clone the repository to your machine and create a new branch for whatever you are working on rather than committing directly to main. Keep branch names short and descriptive, for example feature/mastery-dashboard or fix/quiz-generator-bug.

## Branching and Commits

Each feature or fix should live on its own branch created from main. Write commit messages that describe what changed and why, using the present tense, for example "Add rubric parsing for skill gap detection". Keep commits focused on a single logical change so history stays easy to follow.

## Pull Requests

Open a pull request into main once your branch is ready for review. Describe what the change does, link any related issue, and note anything reviewers should test manually. At least one other team member should review and approve before merging.

## Code Style

Keep code readable and consistent with the surrounding files. Add comments where logic is non obvious, especially around data privacy safeguards and the guardrails that prevent hallucinated feedback. Include tests for new functionality where practical.

## Reporting Issues

If you find a bug or want to propose a new feature, open an issue using the appropriate template so the team has the context needed to prioritise and act on it.
