# Processed datasets (IOG-34)

These three CSVs are the structured view of the approved workbook
`data/dataset/CSE_results_150_students_3_Subjects.xlsx` (150 anonymised
students, three subjects). They are generated by
`src.connect.export_processed` from `src.connect.excel_loader` — not
typed by hand, and not a second parse of the xlsx.

| File | Source function | Meaning |
|---|---|---|
| `grades.csv` | `load_assessment_results()` | One row per student × assessment: subject, assessment, student id, score, marker feedback, SILO tags, weight, weighted score |
| `rubric_comments.csv` | `load_rubrics()` | One criterion per assessment, taken from the Assessment Map |
| `silo_mappings.csv` | `load_learning_outcomes()` | Subject + SILO code + description |

Student identifiers are the anonymised `STU0001`…`STU0150` values from
the workbook. This file was approved for publication by the subject
coordinator; it is not live Moodle data and must not be replaced with
real names or emails.

Regenerate after the workbook changes:

```bash
python -m src.connect.export_processed
```

Keep `data/sample/` and the `.xlsx` as they are. Ge Su owns the raw
workbook (IOG-33). This folder is the IOG-34 export of that ingest.
